# 合盘（双人契合度）规则

> 用户设定（2026-10-01）。用于判断「测算者 A」与「对象 B」八字合不合适。

## 角色约定

- **A = 测算的人**（求测者）
- **B = 被评估的对象**（想知道与 A 合不合适的人）

---

## 一、五行互补（第一层）

### 1. 补忌神：B 化解 A 的多余

A 盘中若有**忌神**五行 X，则看 X 的 **财** 与 **食伤**：

- **X 的财** = X 所克之五行
- **X 的食伤** = X 所生之五行

B 盘中若含这两个五行（越多越好），就能**泄 / 耗 / 化解** A 中多余的 X → **合适**。

> 例：A 水多（水为忌）→ 水之财＝火（水克火）、水之食伤＝木（水生木）→ **B 木火多＝合适**。

（口诀：忌神的「财 + 食伤」＝ 能治它、泄它、耗它的两类五行。以忌神五行为基准取十神，不是以 A 的日主为基准。）

### 2. 相互性（双向，不是单方受益）

- B 补齐了 A 的**用神** → B 把自己的力量给了 A，**可能使 B 的形势变差**。
- 若 A 盘中**也有 B 的用神** → 双向往来 → **互补 → 天作之合**。
- 反之，A 盘中 **B 的忌神多** → **A 会克（消耗 / 拖累）B**。

判定表（先各自定「用神 / 忌神」，再互查）：

| 情况 | 结论 |
|---|---|
| 双方都补对方用神 | ⭐ **天作之合**（互补） |
| 单向补益（一方补另一方，另一方无回馈） | 一方受益、给出方可能受损 |
| A 含 B 的忌神多 | **A 克 B**（伤 B） |
| 互为忌神 | **相克**，最忌 |

判定顺序：① 查 B 是否含 A 忌神的 **财 + 食伤** → ② 查 A 是否含 B 忌神的 **财 + 食伤** → ③ 查双方用神是否互现 → ④ 汇总。

## 二、配偶星与角色（第二层）

### 先问「性取向 + 角色」（必做）

开始看桃花 / 感情 / 合盘前，**先问清性取向**，据此确定**配偶星看哪一类十神**：

| 性取向 | 追问 | 配偶星 | 「有戏」判定 |
|---|---|---|---|
| **异性恋**（一爱 / 四爱同规则） | 男 / 女 | **男看财**（正财=正妻、偏财=偏缘）、**女看官杀**（正官=正夫、偏官=偏夫） | 该方走财 / 官杀运时 |
| **同性恋**（男同 / 女同） | 1 / 0 / T / P（仅确认，不改变取用） | **看比劫**（比肩 / 劫财） | **双方同一时间比劫旺** → 才是可能的配偶 |
| **双性恋** | 「想以哪种身份看哪种对象」 | 再定 | 再定 |

- **四爱与一爱完全一样**：男看财、女看官杀，**不要翻转角色**。
- **同性恋不看财 / 官杀**，只看**比劫**；单方比劫旺无意义，需**双方同期比劫旺**。
- 异性恋只需问「男 / 女」即可，无需再分一爱 / 四爱。
- 已明说的（如「我 gay」「我是 T」）不再问；单盘用本人规则，合盘双方各自定。

### 速查

| 性取向 | 配偶星 |
|---|---|
| 异性恋 · 男 | 财 |
| 异性恋 · 女 | 官杀 |
| 同性恋（男同 / 女同） | 比劫（双方同期旺） |

### 同段时间的引动

- 异性恋**男方**：某时间段走**财运**（正财 / 偏财）→ 感情机会（主动型 / 因财得妻）。
- 异性恋**女方**：同一时间段走**官杀运**（正官 / 偏官）→ 感情机会（受合、被追求）。
- 两人**同一时间段**分别走**财**与**官杀** → **「有戏」**。
- **同性恋**：双方**同一时间段比劫旺** → 才是可能的配偶（单方旺不算）。
- 结合 **大运 ＞ 流年 ＞ 流月**：大运定基调，流年引动，流月定月份。

## 三、运势时间线比对（第三层）

- 看**前几年 + 后续几年**的运势走势（默认取当前年前后各若干年）。
- 两人**感情 / 桃花运势时间点高度重合** → **高概率在一起，且维持相当长时间**。
- 若**后续某段时间对不上**（一方走运、另一方走衰，或桃花点错开）→ 感情**可能没有后续**。

---

## 四、四柱一一对应（第四层）

把 A、B 的**同柱**两两相合（方法与大运流年相同——看关系）：

| 柱 | 对应关系 | 含义 |
|---|---|---|
| 年柱 ↔ 年柱 | **双方家长**的看法（刑 / 冲 / 克 / 害 → 家长会阻挠） |
| 月柱 ↔ 月柱 | 对**当下**的影响 |
| 日柱 ↔ 日柱 | **婚后**的情况：夫妻宫合且为双方用神 → 幸福；**破** → 可能离婚；**刑** → 相处不舒服 |
| 时柱 ↔ 时柱 | **子女**（逻辑同年柱 / 日柱） |

关系一览（脚本自动判定）：

- **天干**：五合、相冲（甲庚 / 乙辛 / 丙壬 / 丁癸）、相克
- **地支**：六合、三合、三会、六冲、六害、相刑、相破

## 五、综合判定顺序

1. **五行互补**（含双向与相克）
2. **配偶星窗口**（② 异性：财 / 官杀同段；② 同性：双方同期比劫旺）
3. **时间线重合度**（前几年 + 后续几年）
4. **四柱逐柱对应**（年 / 月 / 日 / 时）
5. **综合结论**：天作之合 / 互补 / 单向 / 相克；能成 / 有戏 / 无后续

## 六、脚本

`scripts/hepan.py` 输出**机械部分**：

- 两盘四柱（含十神、藏干）
- 五行分布（主气 / 全藏干两种口径）
- 身强弱粗估（**仅供参考**，以第三阶段格局分析为准）
- 四柱逐柱对应关系（天干五合 / 冲 / 克；地支六合 / 三合 / 三会 / 六冲 / 六害 / 刑 / 破）
- 大运 / 流年 / 流月的十神标记（财 / 官杀 / 印 / 比劫 / 食伤）
- 按 `--a-orientation/--b-orientation`（异性 / 同性）取配偶星：异性男看财 / 女看官杀；**同性看比劫**
- 桃花引动时间线（流年 / 流月命中桃花位）
- 配偶星窗口交集（角色适配的「有戏」年份）

> **用神 / 忌神需在分析阶段（SKILL.md 第三阶段）判定后代入**，脚本不自动定用忌，只给身强弱与十神作参考。

用法示例（异性）：

```bash
python3 scripts/hepan.py \
  --a-solar 2007-09-14 --a-hour 20:56 --a-sex 男 --a-role 男 \
  --b-solar 2006-10-30 --b-hour 01:50 --b-sex 男 --b-role 女 \
  --start-year 2022 --end-year 2040
```

同性：加 `--a-orientation 同性 --b-orientation 同性`（配偶星自动改为比劫）。

单盘桃花 / 配偶星扫描用 `scripts/taohua.py`：

```bash
python3 scripts/taohua.py --solar 2007-09-14 --hour 20:56 --sex 男 \
  --orientation 异性 --role 男 --start 2024 --end 2042 --months-year 2026
```
