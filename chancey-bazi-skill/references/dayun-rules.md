# 大运规则详解

## 一、阳年与阴年

天干分阴阳：
- **阳年**：年干为甲、丙、戊、庚、壬
- **阴年**：年干为乙、丁、己、辛、癸

## 二、大运顺逆规则

| 年干 | 性别 | 大运方向 |
|------|------|---------|
| 阳年 | 男 | 顺排 |
| 阳年 | 女 | 逆排 |
| 阴年 | 男 | 逆排 |
| 阴年 | 女 | 顺排 |

口诀：阳男阴女顺排，阴男阳女逆排。

## 三、大运排列方法

以月柱干支为基准，进行顺排或逆排：

### 顺排
从月柱开始，天干和地支各往后推一位，依次排列。

例：月柱为丙寅，顺排大运为：丁卯 → 戊辰 → 己巳 → 庚午 → 辛未 → ...

天干顺推：甲→乙→丙→丁→戊→己→庚→辛→壬→癸→甲（循环）
地支顺推：子→丑→寅→卯→辰→巳→午→未→申→酉→戌→亥→子（循环）

### 逆排
从月柱开始，天干和地支各往前推一位，依次排列。

例：月柱为丙寅，逆排大运为：乙丑 → 甲子 → 癸亥 → 壬戌 → 辛酉 → ...

天干逆推：癸→壬→辛→庚→己→戊→丁→丙→乙→甲→癸（循环）
地支逆推：亥→戌→酉→申→未→午→巳→辰→卯→寅→丑→子→亥（循环）

## 四、起运年龄计算

### 顺排起运年龄
从出生日起，顺数到下一个**节**（注意是"节"而非"气"），计算总天数，除以 3，得数即为起运年龄。

公式：起运年龄 = 出生日到下一个节气天数 ÷ 3

### 逆排起运年龄
从出生日起，逆数到上一个**节**，计算总天数，除以 3，得数即为起运年龄。

公式：起运年龄 = 出生日到上一个节气天数 ÷ 3

### 十二节（用于起运计算）
立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒

注：节与气的区别——每月一节一气，节为月之始，气为月之中。排大运只看"节"。

### 余数处理
- 余 1 天：约 4 个月起运
- 余 2 天：约 8 个月起运
- 余 0 天：整岁起运

四舍五入到最接近的整数岁数。

## 五、大运周期

每步大运管十年。

排列示例（假设 5 岁起运，月柱丙寅，顺排）：
| 大运序 | 年龄范围 | 干支 |
|--------|---------|------|
| 第一步 | 5-14 岁 | 丁卯 |
| 第二步 | 15-24 岁 | 戊辰 |
| 第三步 | 25-34 岁 | 己巳 |
| 第四步 | 35-44 岁 | 庚午 |
| 第五步 | 45-54 岁 | 辛未 |
| 第六步 | 55-64 岁 | 壬申 |
| 第七步 | 65-74 岁 | 癸酉 |
| 第八步 | 75-84 岁 | 甲戌 |

## 六、交运前的小运

小孩未交大运之前（即起运年龄之前），以月柱干支作为大运。

例：如果 5 岁起运，则 0-4 岁这段时间，以月柱的干支来分析运势。

## 七、流年

流年即每一年的天干地支，用来判断当年的运势吉凶。

- 流年干支与原局（四柱）产生的关系（冲、合、刑、害等）影响当年运势
- 流年与大运的关系也很重要：大运为环境，流年为引动
- 大运好、流年差：总体平稳但当年有波折
- 大运差、流年好：总体不利但当年有机遇

## 八、流月

流月即流年之内的每个月干支：以**流年天干**按五虎遁起正月，顺推十二个月。

- 脚本 `scripts/pai_pan.py` 输出 `## 流月`（当前年份十二个月干支，正月→腊月）。
- 流月用于在流年基调上做更细的**月度推演**：指出哪个月引动、哪个月是关键节点。
- 流月干支只由流年天干决定，与个人原局无关（同一流年，所有盘流月干支相同）。

## 九、力量层级：大运 ＞ 流年 ＞ 流月

三者力量大小：**大运 ＞ 流年 ＞ 流月**。层级越高越主导，低层级只在高层级基调上做加减，**不能推翻高层级**。

- **流年促进某事、流月抑制** → 只**减少促进效果**，事情**总体仍朝促进方向走**（打折，不转向）。
- **流年抑制某事、流月促进** → 事情会因流年的抑制作用而**不顺**；相关事件**可能发生**，但最终往往因各种原因**不顺、甚至黄掉**。
- 同理 **大运 ＞ 流年**：大运促进 + 流年抑制 → 减少促进但总体仍促进；大运抑制 + 流年促进 → 因大运作用而不顺，事件可能发生但最后多不顺、甚至黄。

一句话：**顺不顺看高层级（大运 / 流年），快慢大小看低层级（流年 / 流月）。**

### 例外：流月力量被放大、由「关系」主导的情形

出现以下情况时，流月的力量会**放大**，此时起主导作用的是**关系**（不再是单纯的层级高低），不可再简单按「流月弱」处理：

1. **三合 / 三会 / 天克地冲**：当**流年、流月、大运**（及 / 或与原局）构成 **三合、三会** 或 **天克地冲** 时，流月作为引动点力量大幅放大，以该合 / 会 / 冲的**关系**为主导。
2. **冲开财库 / 官库 / 配偶宫**：流月冲动 **财库、官库、配偶宫（日支）** 时，力量放大（主开库 / 破库、婚动、财官引动等）。
3. **引动用神 / 忌神**：流月干支引动了命局的 **用神** 或 **忌神** 时，力量放大（引动用神 → 吉放大；引动忌神 → 凶放大）。

## 十、注意事项

1. 大运的交接年份（换运年）通常变动较大，需要特别关注
2. 大运天干管前五年，地支管后五年（此为一家之言，也有主张天干地支共管十年）
3. 大运与原局形成的天合地合、天克地冲等关系需要重点分析
4. 分析大运时要结合原局格局的喜忌，喜神到位则吉，忌神到位则凶
