# 调候补运（补 / 避）规则

> 用户设定（2026-09-30）。做八字解读时，除格局 / 用神外，**必须**加一层「补 / 避」的生活化建议。

## 判定三步

1. **定候选**：只取与**日主相同阴阳**的五行——
   - 阴日主 → 乙木、丁火、己土、辛金、癸水
   - 阳日主 → 甲木、丙火、戊土、庚金、壬水
   - 异性的五行**不纳入**补 / 避。
2. **筛缺失**：在上述候选中，挑「本盘（四柱天干 + 地支 + 藏干）**没有显现**」者。
   - 触发条件是「**本盘没有这个五行**」，不是笼统的「弱 / 喜用神 / 忌神」。
3. **判益害**：
   - 缺失 + 对盘主**有益** → **补**：建议多接触该类人事物，尤其在该五行对应**时辰**活跃，并可往相应**方位**发展。
   - 缺失 + 对盘主**有害** → **避**：提醒尽量少接触 / 参与该类人事物（内容同下表）。

已有的五行不必补、也避不开。

## 逐五行清单（该五行属于候选、且本盘缺时，其内容 / 时辰 / 方位）

- **木**（木时：寅卯 03:00–07:00 → 偏**东方**）
  - 乙木（阴木）：公园绿植、花草
  - 甲木（阳木）：参天大树、森林；创作、创意类
- **火**（火时：巳午 09:00–13:00 → 偏**南方**）
  - 丁火（阴火）：绘画等**不用抛头露面**的文艺活动
  - 丙火（阳火）：唱歌跳舞等**需要抛头露面**的活动
- **土**（土时：辰/未/戌/丑 07:00–09:00、13:00–15:00、19:00–21:00、01:00–03:00 → 多在**老家周围**）
  - 己土（阴土）：田园活动
  - 戊土（阳土）：登山类活动
- **金**（金时：申酉 15:00–19:00 → 偏**西方**）
  - 辛金（阴金）：珠宝
  - 庚金（阳金）：武术、健身
- **水**（水时：亥子 21:00–01:00 → 偏**北方**）
  - 癸水（阴水）：游泳
  - 壬水（阳水）：湖海

## 用法

先定日主阴阳 → 选出同阴阳的 5 个候选五行 → 查本盘缺哪些 → 判其益 / 害 → 给「时辰 + 活动 + 方位」补法，或「回避」提示。

## 示例

- 本盘 丁亥 己酉 辛亥 戊戌，日主辛金=阴：候选 = 乙木/丁火/己土/辛金/癸水；本盘已有丁/己/辛，**缺乙木、癸水** → 缺乙木（有益）补绿植花草；缺癸水（有害）避游泳。
- 本盘 丙戌 戊戌 壬辰 辛丑，日主壬水=阳：候选 = 甲木/丙火/戊土/庚金/壬水；本盘已有丙/戊/壬，**缺甲木、庚金**（益 / 害按盘定）。
